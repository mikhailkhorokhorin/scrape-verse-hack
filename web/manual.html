THWIP THE WATCH MANUAL

THWIP

Scrapers do not crash, they rot. This is the back page of the issue: how to install the watch, how to drive it from an agent, and how to break it yourself. Every command here is one that runs — no pseudo-code, no placeholders.

1 · Get the watch

Clone it, prove it, connect it. The clone and the suite spend nothing and need no key; the last line hands the fleet to your coding agent.

git clone https://github.com/mikhailkhorokhorin/scrape-verse-hack.git
cd scrape-verse-hack
npm test
claude mcp add thwip -- node mcp/server.js

1,136 tests, node:test, zero dependencies, offline. No network and no bdata calls — the credit-spending paths run against a mocked lib.bdata.

To see the console rather than the code, serve the repo over HTTP with python3 -m http.server 8000, then open /web/. Opening the file directly shows an error plate: the page fetches two JSON files, and browsers block fetch on file:// origins.

2 · Drive it from an agent

Eight tools over stdio JSON-RPC 2.0, written straight against the spec: no SDK, no dependencies. Six read the committed data: instant, free, no network. The other two spend Bright Data credit and declare it in their own tool descriptions, so a well-behaved agent asks before it bills you.

  • fleet_status Latest run for every Spider — integrity, status, rows, live fields, collector_id FREE
  • spider_history Run history for one Spider, oldest first, with post-heal runs marked FREE
  • incident_log Every recorded break, with strain, integrity delta and resolution FREE
  • heal_receipt Full timestamped receipt for one incident, beside the collector_id that did not change FREE
  • evidence_report The whole trail: stage durations, per-field before and after, SHA-256 digests recomputed from disk FREE
  • numbers_audit Every number the console shows, recomputed by a second implementation that shares no code with it FREE
  • scan_fleet Live scrape through Bright Data, scored field by field SPENDS CREDIT
  • heal_spider Diagnose, re-weave, verify with a fresh scrape, open an incident SPENDS CREDIT

Exercise the server with no API key at all. This prints every phase beside the unchanged collector_id, then the per-field verification table:

printf '%s\n%s\n' \
  '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"x","version":"1"}}}' \
  '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"heal_receipt","arguments":{"incident_id":"inc_001"}}}' \
  | node mcp/server.js

3 · Judge it in ten minutes

Six things, in this order. The first three take under two minutes each; the last three are one command apiece.

  1. Open the console

    The opening sequence replays inc_003, a real recorded incident, not a mock. Scroll to Incident Feed: three cards, each a comic issue with its own permalink. The note above the feed counts the breaks that happened on sites we do not control. Open the watch →

  2. Check requirement 4 in one command

    Clone, then run the heal_receipt one-liner from section 2. It prints every phase beside the unchanged collector_id, then the per-field verification table. No API key, no network, no credit.

  3. Run the suite

    npm test

    1,136 tests, node:test, zero dependencies, offline, spends nothing.

  4. Break one yourself, in the browser, in ten seconds

    The CHAOS LAB route opens a synthetic fleet running the real mechanics. The three clicks are in section 4.

  5. Print the evidence trail

    node tools/evidence-report.js

    For each incident: the collector id on both sides of the repair (asserted identical), the stage durations, the value every field held before and after, the verdict, and SHA-256 digests recomputed from the committed files at call time.

  6. Count what no human did

    git log --author="thwip watch" --oneline | wc -l
node tools/numbers-audit.js

    The first counts the commits the workflow authored rather than a person. The second recomputes every number the console shows from the committed JSON, by a second implementation that shares no code with the console.

4 · Break it yourself

The fleet in this mode is synthetic and the page says so at the top. The mechanics running it are the same code the live console uses.

OPEN THE CHAOS LAB →

  1. BREAK BODEGA The substance climbs the panel — its spread is the integrity deficit, so the black is the number rather than an effect.
  2. DRAG ACROSS IT The black tears away, showing the values that actually came back.
  3. RE-WEAVE The receipt prints, carrying the per-field was and now table.

Add ?capture=1 to hide every control for a clean screenshot. The real console lives on the plain route and never falls back to synthetic data — it shows honest empty states until the cron has committed a scan.
