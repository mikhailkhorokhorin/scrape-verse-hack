The Watch

How to read a Spider

A scraper that breaks does not crash — it keeps running and the rows go quietly wrong. The black is what the scraper lost. It climbs each panel from the base, covering exactly as much of the Spider as its Integrity is missing. Nothing else on this page needs reading to know which Spider is in trouble.

State

  • HealthyIntegrity 90+, every field returning
  • Degraded60–89, fields starting to fail
  • CriticalUnder 60, the panel glitches
  • Re-weavingA repair is running now
  • UnwatchedNo scan in 3 hours — it sinks into the page

Field

  • ✓ titleValue arrived and is valid
  • ⚠ priceValue arrived and is wrong — passes every null check, poisons the pipeline
  • ✗ ratingValue is null or empty

Size

  • Critical & re-weavingTake the page — the splash frame
  • DegradedFull diagnosis, half the width
  • HealthyShrinks to a strip — nothing to diagnose

Size is data. You never scan for the problem; the problem takes the page.
