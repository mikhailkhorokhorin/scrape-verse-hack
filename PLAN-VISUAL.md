### Протокол проверки анимаций (выстрадан, нарушение = потерянные часы)
1. «Анимация написана правильно» → прокрутка: `anim.pause(); anim.currentTime = N` + `getComputedStyle`.
2. «Анимация реально идёт» → сэмплирование по реальному времени через `requestAnimationFrame`. Скриншоты Playwright ЛГУТ по таймингу (тормозят страницу) — числам rAF верить больше, чем кадрам.
3. Перед замером — `{waitUntil:'networkidle'}` и свежая навигация: браузер кеширует старый CSS, из-за этого дважды «находились» несуществующие баги.
4. Инлайновый стиль бьёт класс. Глушить анимации только классом (`.sheet--silenced`), чистить `removeProperty`.
5. Селектор-потомок ловит клоны: `.modal.is-tearing .sheet` прятал и клоны внутри сцены — только `>`.
6. Windows: следить за CRLF/LF. Python `io.open` без `newline=''` перебивает переводы строк, а тесты режут CSS по `\n}\n`. Править файлы с `newline=''` или Edit-инструментом.
7. Paint-свойства (`mask-position`, `stroke-dashoffset`, `filter`) не анимировать. Уже ловили 36→121 FPS на одной такой анимации.

### Задача 2 — Страница MANUAL: Человек-паук на нити слева

- Качание брать готовым классом `gutter__swing` (`gutter.css:143`), у него уже есть `--sway`/`--phase` из `gutterSway()`; для своего `transform-origin` добавить модификатор по образцу `.gutter__swing--sac{transform-origin:28px 0;}`.

**Риски.** Художественная: силуэт должен читаться человеком-пауком с одного взгляда — обязательный скриншот и взгляд глазами, не структурный тест. Строчный бюджет manual-страницы.

### Задача 3 — Анимации по hover (логотип, пульс, всё остальное)
**Что хотим.** Всё, что умеет проигрываться по клику/само — проигрывается и при наведении. Явно: паутина логотипа THWIP (сейчас `web/js/sheets/front/thwip-shot.js` вешает только `click` на `.wordmark__word`), пульс LIVE (`.pulse`), и пройтись по остальным одноразовым эффектам.

**Как.**
- Общий хелпер `hoverReplay(el, fire, cooldownMs)`: `mouseenter` → если не в кулдауне → `fire()`. Кулдаун = длительность анимации + ~200ms, чтобы ёрзанье мышью не спамило рестарты. Клик оставить как был.
- Логотип: `mouseenter` на `.wordmark` → тот же путь, что клик (`thwipReshoot`). Не дублировать логику — дернуть существующую функцию. **РАЗВЕДАНО:** `thwipFire()` (`thwip-shot.js:180`) уже имеет собственную защиту от повторного запуска через `mark.dataset.firing` и снимает её по `THWIP_HOLD` — переиспользовать её, а не городить вторую. Слушатель вешается в `mountThwipShot()` (строка ~212), там же добавить hover. `thwip-shot.js` = 219 строк, до лимита 31 — хелпер выносить в отдельный файл `web/js/fx/hover-replay.js`.
- `thwip-shot.js` подключён на ОБЕИХ страницах (index.html и manual.html) — hover заработает сразу везде.
- Пульс: рестарт CSS-анимации приёмом remove class → `void el.offsetWidth` → add class (НЕ инлайновым `style.animation`).
- Инвентаризация остальных hover-кандидатов: спарклайны панелей, `wordmark--fire`, gutter-мотивы (клаймбер), пульс в readout. Каждому — тот же хелпер. Touch-устройства: `mouseenter` не мешает, клик остаётся основным.
- `prefers-reduced-motion` — hover-триггеры молчат.

**Риски.** Двойной запуск (hover сразу перед click) — решается кулдауном. Утечка слушателей на пересоздаваемых узлах (панели перерисовываются) — вешать делегированием или при каждом рендере.

**Приёмка.** Наведение на логотип запускает паутину; повторное наведение после окончания — снова запускает; клик работает; rAF-замер подтверждает реальный старт.

## 2. Оптимизация под GitHub Pages (обязательная волна)

GH Pages = статика без сервера, слабые машины зрителей, холодный кеш. Что делаем:

1. **Добить известный анти-паттерн:** `web/css/fleet/panel.css:43` — `symbiote-breathe` всё ещё анимирует `mask-position` под turbulence-фильтром на панелях (fleet.css и empty.css уже вылечены, panel.css остался). Это уже давало 36→121 FPS на главной.
   **Готовый рецепт (структура идентична вылеченной):** `.symbiote` (panel.css:32) — родитель с `filter:url(#symbiote-turbulence)`, `.symbiote__body` (:36) — ребёнок с маской и анимацией. Снять `animation` с ребёнка (маска станет статичной), повесить на РОДИТЕЛЯ новые keyframes с `transform:translateY(0 → -2..-3px)` — transform применяется после фильтра, композитор не перерастеризует turbulence. Образец — `web/css/fleet/fleet.css:1-7`: там `inset:-20px` даёт overscan под сдвиг, для `.symbiote` (у него `inset:0`) добавить такой же небольшой отрицательный inset, иначе на сдвиге оголится край. Keyframes держать в panel.css (fleet.css и empty.css уже отвязаны от общих).
   **Замер в покое ДО работ: 20 infinite-анимаций** (`grep -rn "infinite" web/css/**/*.css | wc -l`) — цифра для сравнения после.
2. **Инвентаризация infinite-анимаций в покое** (`document.getAnimations()` на живой странице): каждая либо дёшева (transform/opacity, мелкий слой), либо останавливается вне вьюпорта через IntersectionObserver (`animation-play-state:paused` классом). Особенно новые: окна Bugle, качание Человека-паука.
3. **`will-change`-бюджет:** пересчитать элементы с постоянным will-change; убрать с тех, что не анимируются прямо сейчас (уже известно ~78 узлов в gutter/rig — после фикса №1 перезамерить, если вклад нулевой, не трогать).

## 4. Definition of Done всего плана
